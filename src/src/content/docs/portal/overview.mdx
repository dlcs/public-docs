The IIIF Cloud Services Portal (Beta) provides a browser-based interface for managing digital assets, creating and editing IIIF Manifests and Collections, and administering users — without needing to write code.

Some of the core features available in the portal include:

- Uploading and managing digital assets in Spaces
- Creating and editing IIIF Manifests and Collections
- Creating and editing Exhibition Manifests
- Importing existing external IIIF content
- Managing IIIF content with folders and templates
- Portal User management

🚀 **Latest v1.5 release (October 8th) includes**:

* ✅ Support for the creation and management of Exhibition Manifests
* ✅ New functionality to support creation of IIIF Manifests directly from individual Spaces
* ✅ Search across feature allowing users to search for IIIF content within their tenant
* ✅ Improved handling of special characters when uploading assets into Spaces
* ✅ In platform links to the new documentation site for the IIIF Cloud Services
* ✅ Security and usability improvements

Development of additional IIIF Publishing specific features is ongoing alongside development of the IIIF Cloud Service APIs, with further features expected to be released before the end of 2026.

## Known issues

<Aside type="caution">
The following known issues exist in the current release. Please contact [support.iiif-cs@digirati.com](mailto:support.iiif-cs@digirati.com) if you encounter unexpected behaviour.
</Aside>

- The IIIF specification permits the addition of IIIF Collections to themselves; however, in this version of the portal this is not permitted. You can add valid IIIF content once to a Collection — it is not possible to save the same item twice in the same collection.
- When you add internally hosted resources to a IIIF Collection within the portal, these items (Manifests or other Collections) don't currently allow you to navigate or link directly to them. This functionality will be available in the next minor release.
- With IIIF Collections managed within the portal, if an internally hosted Manifest or Collection is moved or its slug is changed then it will break the link in the Collection and will need to be removed and re-added.
